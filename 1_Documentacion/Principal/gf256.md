# src/gf256.py (Módulo 1: álgebra de GF(2⁸))

**Para qué existe:** construir la S-box de AES desde cero, con la que se comprueba que el evaluador mide bien (regresión NL = 112, δ = 4). El AG no usa este módulo.

## Funciones

| Función | Qué hace |
|---|---|
| `gf_mul(a, b)` | Multiplica en GF(2⁸) con el algoritmo "shift-and-add": suma (XOR) `a` cuando el bit de `b` es 1, desplaza `a` a la izquierda y, si se desborda el bit 8, reduce con el polinomio `POLY = 0x11B` (x⁸ + x⁴ + x³ + x + 1). |
| `gf_inv(a)` | Inverso multiplicativo por búsqueda directa (b tal que a·b = 1). Por convención de AES, `inv(0) = 0`. |
| `affine(x)` | Transformación afín de AES: `x ⊕ rotl(x,1) ⊕ rotl(x,2) ⊕ rotl(x,3) ⊕ rotl(x,4) ⊕ 0x63`. |
| `aes_sbox()` | `affine(gf_inv(x))` para x = 0 … 255. Devuelve la S-box de AES como lista. |

## Cómo se verifica (`tests/test_gf256.py`)

- Valores conocidos de FIPS-197: `S[0x00] = 0x63`, `S[0x01] = 0x7C`, `S[0x53] = 0xED`.
- Ejemplo de FIPS-197: `{57}·{83} = {c1}`.
- La S-box es una permutación y `a·inv(a) = 1` para todo a ≠ 0.

## Notas

- `gf_inv` es O(256) por llamada; no importa porque solo se usa una vez para construir AES.
